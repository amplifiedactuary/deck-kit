# 26 · Insurance navy

> **PLACEHOLDER — experiment, not talk content.**

One of 12 palette experiments sharing identical content (kicker → headline →
four-stat strip → closing line) so palettes compare like-for-like in the
overview gallery.

**This palette:** *insurance navy* — corporate navy (#10243e) ground with
gold/brass (#c9a227) accents, warm ivory text, conservative detailing: hairline
gold rules with centred lozenges, a low-opacity heraldic shield watermark, a
thin gold page border, and a classical centred composition. The deliberate
"trojan horse": it looks like the audience's own annual report — Big-4 keynote
polish, executed straight — with a Northwind Insurance FY 2025 KPI story.
